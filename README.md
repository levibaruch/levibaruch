## Projects
**Dance-Face** *(Closed Source)*  
GDPR compliant web application that allows dancers to find their images based on a supplied image of themselves. Besides this, I am working on an segmentation model that can distinguish between the latin (rumba, cha-cha-cha, samba) and standard (waltz, tango, quickstep) dances based on pose vectors and image information.

**TNO-Panoptes** *(Proprietary)*
U-Net segmentation solution to extract Perclos (Percentage of Eye closed) data from the _Pupil Labs_ PupilCore eye tracker video information. From this, blink features can be extracted which give an indication into circadian fatigue. 

**[DataCheck](https://github.com/levibaruch/datacheck)** 
Using a combination of LLM inference and deterministic algorithms, DataCheck can analyse research data repositories, label its files based on purpose and reconstruct the repository into PsychDS. Doing this, feedback is given to authors to better structure their repository and/or include metadata. Developed and validated during MSc. thesis project and implemented into [MetaCheck](https://github.com/scienceverse/metacheck) as a package.

**[PsychTrove](https://github.com/levibaruch/PsychTrove)** 
A dataset browser built on top of the Psych-DS structured output that DataCheck produces. Using the metadata generated by DataCheck it allows the browsing of repositories on variable level.

**[refexplorer](https://github.com/levibaruch/refexplorer)**  
Small tool for literature review that finds potentially interesting papers that you missed by crossreferencings citations and references of the bibtex corpus supplied using OpenAlex and other bibliography tools.

**[papertrail](https://github.com/levibaruch/papertrail)**  
Citation verification. Point it at a paper and a folder of its references; it uses Claude to check whether each factual claim the paper makes is actually supported by what it cites. Produces a structured verdict per claim: accurate, slightly inaccurate, inaccurate, or unverifiable. Uses mega lots of usage but very efficient in factchecking yourself (or your professors!)
